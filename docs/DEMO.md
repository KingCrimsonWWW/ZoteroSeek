# 5 分钟演示脚本

面向面试/录屏：从「库里有 170 篇 PDF」到「带出处的回答 + 侧边栏核对」的完整闭环。

## 0. 环境（30 秒）

```powershell
cd E:\TheCode\ZoteroSeek
node evals/doctor.mjs
```

预期看到：Zotero 已连接（242 条对象 / 170 个 PDF）、MinerU token 可用、索引 10 篇 / 281 分块。

**讲点**：Zotero 只读、MinerU 是唯一解析器、token 失效会在面板状态条直接红点提示。

## 1. 侧边栏（60 秒）

1. 点输入框左侧的 ZS 图标按钮（悬停提示「文献库」）→ 打开右侧边栏面板；
2. 「文献」页搜索 `空洞`，选中一篇中文硕士论文 → 点「入库」（已入库的直接进「阅读」）；
3. 「阅读」页展示 MinerU 转出的 Markdown：章节标题、三线表（HTML）、公式（LaTeX）、插图都在；
4. 在阅读页的检索框里问「空洞深度对频率的影响」→ 切到「检索」页看到命中片段；
5. 勾选两条 → 「引用到对话」→ 引用出现在输入框里。

**讲点**：不显示 PDF 原文，而是直接读 MinerU 的结构化 Markdown；每个片段带 `chunk_id`、章节路径、页码，选中的引用能回到对话里继续用。

## 2. 对话问答（90 秒）

在会话里问：

```text
我文献库里关于「隧道衬砌背后空洞」的检测方法有哪些？各自有什么局限？
```

Agent 会先调 `zotero_search`，再基于带页码的片段作答，引用形如 `[来源: EVRF6GD8:0055]`。

追问（验证「不编造」）：

```text
那篇 2026 年用激光多普勒测轨道板脱空的论文，实验里测点是怎么布置的？
```

预期答案含：10 cm 网格、225 个测点、每个测点 5 次冲击 —— 全部来自 `EHC5UR3B:0010`。

再演示跨语言：用中文问一篇**英文**文献的细节（这是 0.1 版会零命中的场景）：

```text
轨道板脱空 激光多普勒测振 检测
```

工具输出会先说明「跨语言扩展：脱空→void、轨道板→track slab、激光多普勒→laser doppler vibrometry 等 17 个」，
然后每条命中标注「命中=跨语言扩展」。

最后问一个库里没有的话题（例如「量子计算对隧道检测的影响」）→ 回答「文献库中没有相关内容」。

**讲点**：系统提示词里的引用契约 + 工具返回的 `chunk_id` 让「引用」可以被程序核对；检索不到时明确说没有，而不是编。

## 3. 评测数字（90 秒）

```powershell
node evals/run-eval.mjs
```

预期：`recall@5 = 0.92`、`MRR = 0.80`、`hit_rate = 1.0`（检索侧，无模型、可复现）。

生成侧（会话内调 `zotero_eval` 工具）：
`citation_accuracy = 1.0`、`answer_rate = 1.0`、平均 2.44 条引用/答案。详见 `evals/RESULTS.md`。

**讲点**：评测拆成检索侧与生成侧；生成侧的引用校验是「解析 `[^N^]` → 校验编号落在本轮检索集合 → 不合法先纠正重试一次、再失败就剥离」，不靠模型自评。

## 4. 架构一页纸（60 秒）

见 `docs/ARCHITECTURE.md`，口头版：

- 单个 DSH 插件（零运行时依赖）：Host 半边注册 5 个工具 + `/zotero-seek` 面板路由；Client 半边是右侧边栏面板；
- MinerU 解析产物按「PDF 内容 sha1 + 解析参数」寻址缓存，同一份 PDF 换条目不会重复花钱；
- 分块从 MinerU 的 `content_list.json`（带 `page_idx`/`bbox`）出发，章节栈 + 表格/公式原子块；
- 检索是两路 BM25 + 准入 + RRF：原查询 / 原查询+领域双语词表扩展；命中带 matchKind；中文问英文文献 recall@5 0.07→0.79；
- 索引降噪：标题行、版面标签、参考文献列表都不进索引；
- 引用写成 `[来源: chunk_id]`，可事后核对。

## 常见追问与回答

| 追问 | 回答 |
|---|---|
| 为什么不用向量库？ | 本库 3.5k 分块，BM25 建索引 1.4s、单查询亚毫秒；词面检索可解释、零模型下载。语义检索是二期的 RRF 融合项，不是没考虑。 |
| 中文问英文论文怎么办？ | 当前会退化（词面无交集），已记录在 `evals/RESULTS.md` 的局限里；二期加语义召回或查询翻译。 |
| MinerU 挂了怎么办？ | 解析失败即失败，不用别的来源拼凑；工具返回稳定错误 kind，面板直接显示原因。 |
| 引用会不会错？ | 引用编号必须落在本轮检索结果里；非法引用先纠正重试一次，再失败就剥离并标注 `citations_stripped`。citation_accuracy 由脚本判定。 |
| 面板为什么走 HTTP 而不是 Remote？ | 面板只是本插件私有数据面，HTTP 路由零代码生成成本；代价是只能绑 127.0.0.1，且只做只读 + token 保存。 |
